## Word-frequency data

The English and Spanish JSON word lists are derived from wordfreq 3.1.1, by Robyn Speer and contributors: https://github.com/rspeer/wordfreq

The lists were reduced to common alphabetic words for offline prefix completion. They remain available under Creative Commons Attribution-ShareAlike 4.0: https://creativecommons.org/licenses/by-sa/4.0/

See licenses/wordfreq-NOTICE.md for the upstream data sources and attribution requirements. The wordfreq code license is preserved in licenses/wordfreq-code.txt; the wordfreq Python package is not required at runtime.
